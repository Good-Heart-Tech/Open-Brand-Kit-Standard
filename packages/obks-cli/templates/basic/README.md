# {{displayName}} brand kit

![Colors](tokens/exports/svg/palette.svg)

This folder is where **{{displayName}}** keeps its brand: colors, logo, and a
short description of who we are and how we sound. It follows the
[Open Brand Kit Standard](https://github.com/Good-Heart-Tech/Open-Brand-Kit-Standard).

## Start here

- **Read [`BRAND.md`](BRAND.md).** It is the one-page version of the brand.
- **Colors** live in `tokens/colors.obks.json`. **Logo** files live in `assets/logo/`.
- This kit is **basic**. It does not need to be complete. Add more when you are ready,
  or point to the tool that already covers it (see `sections` in `brandkit.yaml`).
- Sharing is **private** by default. Nothing leaves this folder unless you choose to share it.
